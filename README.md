# Quantum Lab

Bilingual (Arabic / English) landing page for Quantum — software, AI, Arduino & tech training.

Built with React 19, TanStack Start, Vite and Tailwind CSS v4.

## Development

```sh
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run preview`, `npm run test`, `npm run lint`.

All site copy and contact details live in `src/lib/content.ts`.
